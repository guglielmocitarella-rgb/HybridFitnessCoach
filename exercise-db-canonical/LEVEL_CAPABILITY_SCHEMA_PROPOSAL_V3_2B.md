# Exercise DB V3.2B — Minimal Capability Schema Proposal

Status: proposal only; no runtime schema change in V3.2B.

- `technicalDifficulty`: motor/technical complexity; future ranking/safety.
- `strengthRequirement`: relative strength demand mapped to existing capability axes; needed for a semantically correct replacement of scalar strength gating.
- `mobilityRequirement`: range-of-motion prerequisite; future eligibility once assessed.
- `balanceCoordinationRequirement`: balance/coordination prerequisite; future eligibility/ranking.

Do not add `skillRequirement` as a competing scalar: SkillCatalog prerequisites/mastery remain authoritative.
