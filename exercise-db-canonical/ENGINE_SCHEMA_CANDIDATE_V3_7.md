# Exercise DB V3.7 — Engine Schema Candidate

Minimum sufficient schema derived from V3.1–V3.6. Equipment state/mode, resistance/load/assistance, multidimensional capability, typed skill relations, category/group, multidimensional prescription and 0..n movement patterns are distinct. Legacy payload is preserved exactly for losslessness. Unknown is never normalized to NONE. Legacy level is never blindly mapped.

Runtime DB modified: **NO**. Adapter is specification only.
