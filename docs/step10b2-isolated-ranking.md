## Requirement policy

The existing V3SelectionEngine and V3PdStrengthResolver remain the eligibility authority. Score never rescues a rejected exercise; rejected rows have null score, no contributions, and preserved rejection reasons.

| Requirement/context | Decision |
|---|---|
| KNOWN requirement and compatible KNOWN assessment | Eligible for this dimension; other gates still apply |
| KNOWN requirement above assessed capability | Excluded: CAPABILITY_INSUFFICIENT |
| UNKNOWN requirement or missing transversal assessment | Unresolved and excluded: CAPABILITY_UNRESOLVED |
| NOT_APPLICABLE | This dimension imposes no assessment requirement |
| PRESCRIPTION_DEPENDENT strength | Existing resolver requires exact exercise, source, work dimensions, resistance/unit, and athlete capacity envelope |
| Missing PD prescription / capacity / mismatched envelope | Explicit PD_STRENGTH_CONTEXT_INSUFFICIENT, ATHLETE_CAPABILITY_UNKNOWN, or CAPACITY_ENVELOPE_MISMATCH |
| Invalid or unsupported PD context | Explicit invalid/unsupported rejection; no substitution of guessed parameters |
| EVIDENCE_UNRESOLVED | TERMINAL_CANONICAL_STATE; additional capacity cannot resolve canonical evidence |
| Future unsupported PD technical/mobility/balance requirement | Fail-closed CAPABILITY_UNRESOLVED |
